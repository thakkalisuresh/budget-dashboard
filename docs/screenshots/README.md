# Screenshots

Drop PNG/WebP captures here and they'll be embedded in the root [README](../../README.md#screenshots).

## Suggested set

| File | What to capture |
|---|---|
| `dashboard.png` | Main budget view — stat cards, expense table, donut + bar charts |
| `split.png` | **Split** tab — you-vs-partner totals, comparison bar, per-category breakdown |
| `cards.png` | **Cards** tab — per-card spend + rewards analytics |
| `mobile.png` | Mobile layout — bottom nav + a tab (shows the PWA / responsive design) |
| `dark.png` _(optional)_ | Dark mode, to show theming |

## Tips

- Use a clean month with realistic-but-not-sensitive numbers (or blur balances).
- Desktop shots ~1280px wide; mobile ~390px wide.
- Keep files reasonably small (compress; aim < ~300 KB each).

## Embedding

Once added, replace the placeholder in the root README's **Screenshots** section, e.g.:

```html
<p align="center">
  <img src="docs/screenshots/dashboard.png" width="80%" alt="Dashboard" /><br/>
  <img src="docs/screenshots/split.png" width="48%" alt="Split tab" />
  <img src="docs/screenshots/cards.png" width="48%" alt="Cards tab" />
</p>
```
